# 上游来源参考 / Upstream Sources Reference

> 本仓库（Oasisic-Icons）现已作为**独立最高上游**，不再自动同步任何外部图标库。  
> 本文仅用于记录历史来源，便于后续维护时追溯素材出处。

---

## 1. Qure（Koolson/Qure）

- **仓库**：https://github.com/Koolson/Qure
- **定位**：早期主力图标来源，包含大量品牌彩色图标。
- **特点**：目录按客户端分类（`Color/`、`Mini/` 等），命名与本仓库规范不同。
- **与本仓库关系**：
  - 重构前，部分图标直接来自 Qure 对应目录。
  - 重构后（`2e771d1` 之后），所有图标已统一归入 `icons/<Category>/<Brand>/` 结构并完成规范化。
  - **不再同步**：本仓库不再从 Qure 拉取更新。

## 2. Semporia/Hand-Painted-icon

- **仓库**：https://github.com/Semporia/Hand-Painted-icon
- **定位**：手绘风格图标集，部分品牌仅有此源有素材。
- **特点**：风格统一，但数量少于 Qure。
- **与本仓库关系**：
  - 早期作为补充来源，填补 Qure 未覆盖的品牌。
  - 重构后所有素材已融入本仓库目录结构。
  - **不再同步**：本仓库不再从此源拉取更新。

## 3. 官方品牌资源

- **来源**：各品牌官方网站、Favicon、公开 CDN（如 `brandmark.io`、品牌官网 `/favicon.ico`）。
- **特点**：像素级准确，但尺寸/底色/圆角不统一。
- **与本仓库关系**：
  - 作为权威依据，优先于第三方图标集。
  - 经 `scripts/normalize-icons.py` 统一为 512×512 / RGBA / r=115px Apple squircle。

## 4. 其他参考来源

| 来源 | 用途 | 说明 |
|------|------|------|
| simple-icons | 补充无素材品牌 | 矢量图转 PNG，再规范化 |
| brandmark.io | 官方 logo 下载 | 仅用于缺失品牌的兜底 |
| 品牌官网 / favicon | 权威素材 | 优先采用 |

---

## 为何不再同步上游

1. **质量不一致**：上游图标尺寸、色型、圆角、底色各异，每次同步都需要大量人工校正。
2. **规范漂移**：上游更新会破坏本仓库已建立的命名/结构/质量规范。
3. **独立可控**：本仓库已完成全量规范化（512×512 / RGBA / r=115），成为事实上的最高上游。
4. **贡献者可直投 PR**：新增/替换图标直接提 PR 到本仓库，不走外部同步。

---

## 维护建议

- 如需补充新图标，优先从**官方品牌资源**获取，再运行 `scripts/normalize-icons.py --apply` 规范化。
- 若上游某图标质量显著优于本仓库当前版本，可手动替换后提交 PR，不必等自动同步。
- 本文档作为历史追溯依据，不构成同步承诺。
